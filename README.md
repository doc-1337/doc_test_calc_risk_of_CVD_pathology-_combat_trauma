# Калькулятор ризику серцево-судинної патології при бойовій травмі

**Інструмент для кількісної оцінки ризику розвитку вторинної патології серцево-судинної системи у постраждалих з бойовою травмою.**

## 📚 Про метод
Розрахунки базуються на методиці, розробленій Н. М. Сидоровою та співавт. (2020).
*   Джерело: Sydorova N.M. et al. Розрахунок ризику розвитку серцево-судинної патології... World Science. 2020. №2(54). Vol.1. С. 35-42.[reference:3]
*   DOI: [10.31435/rsglobal_ws/28022020/6928](https://doi.org/10.31435/rsglobal_ws/28022020/6928)
